# 时光 · 会看时间的 DeepSeek

一个装在手机主屏上的聊天 App：接你自己的 DeepSeek Key，它知道现在几点、你们多久没聊，
在深夜、清晨、饭点这种合适的时候自然关心你一句——但绝大多数回复里根本不提时间。

---

## 先说清楚形式：为什么是"网页 App"而不是 APK

这台开发机没有 Android SDK / Gradle，沙箱里也没有外网（下不了 SDK），
所以没法在这里直接编译出 `.apk`。因此做成了 **PWA**：用 https 网址打开后
「添加到主屏幕」，安卓上就是一个全屏、带图标、能离线打开的独立 App，体验和原生几乎没差。

如果你确实要一个能转发的 `.apk` 文件，README 最后有 **PWABuilder** 的路线（需要你先部署网页）。

## 5 分钟上手

### 第 1 步：拿 API Key

1. 打开 <https://platform.deepseek.com/api_keys>，登录后创建 Key（`sk-` 开头），复制。
2. 同一个站点里充几块钱。按量计费，日常聊天一次也就几分钱。

模型名填 `deepseek-flash`（当前默认，快且便宜）或 `deepseek-v4-pro`（更强，更贵）。
设置里是输入框 + 候选，接口改了模型名你直接手输就行。

### 第 2 步：把 App 放到一个 https 网址上

**必须 https**，否则不能「添加到主屏幕」、也没有离线缓存。

- **GitHub Pages（推荐，免费）**
  1. 新建一个仓库，把 `index.html`、`manifest.webmanifest`、`sw.js`、`icons/` 传上去（保持同样结构）
  2. 仓库 Settings → Pages → Source 选 `Deploy from a branch` → `main` / `(root)` → Save
  3. 等 1 分钟，访问 `https://你的用户名.github.io/仓库名/`
- **Cloudflare Pages**：Create → Upload assets → 整个文件夹拖进去
- **只想先看看界面**：电脑上双击 `index.html`。界面能用、能聊天，但没有离线缓存和安装。

### 第 3 步：装到手机

1. 手机 Chrome 打开上面的网址
2. 右上角 ⋮ → **「添加到主屏幕」**（或「安装应用」）
3. 桌面出现「时光」图标，点开是全屏的
4. 点右上角 ⚙ → 粘贴 Key → **测试连接** → 出现 ✓ 就可以聊了

## 如果「测试连接」报连不上

先判断是网络问题还是跨域（CORS）问题：

- 手机浏览器直接打开 <https://api.deepseek.com>，如果也打不开 → 是网络问题
- 能打开、但 App 里报连不上 → 基本就是 CORS

解决 CORS：部署 `proxy/cloudflare-worker.js`（免费，约 3 分钟）：

1. <https://dash.cloudflare.com> → Workers & Pages → Create → Worker
2. 把该文件内容整段贴进去，Deploy
3. 得到地址，例如 `https://shiguang.你的名字.workers.dev`
4. App 设置 → **自定义接口地址** → 填这个地址（不用加 `/chat/completions`）

**更安全的玩法**：在 Worker 的 Settings → Variables 里加一个 Secret `DEEPSEEK_API_KEY`，
手机端就可以完全不填 Key，请求由 Worker 补上，Key 不落在手机里。

## 时间感知的实现（重点）

每次发消息前，代码会做三件事：

1. **把时间写进系统提示词**：`2026年5月1日 23:41，星期五，深夜`，外加"距上次聊天 3 小时前"。
   所以问它"现在几点"它是真的知道。
2. **注入行为规则**：明确告诉它「知道时间，但不要为了显得知道而硬提」「一条回复最多一处」
   「对方在讲正事/情绪低落时，先回应内容」。
3. **用代码控制提醒闸门**，不靠模型自觉：
   - 同一时段每天最多提醒 **一次**
   - 两次提醒之间至少隔 **45 分钟**
   - 深夜跨零点算「同一晚」（23:30 提醒过，凌晨 1 点不会再提）
   - 选「不打扰」时完全不注入提醒

设置的「核对一下 → 查看本轮系统提示词」里，能看到本次真正发出去的提示词，方便你自己调。

**提醒时段**（想改就改 `index.html` 里的 `SLOTS` 数组）：

| 时段 | 时间 | 它会做什么 |
|---|---|---|
| 深夜 | 23:30–05:30 | 劝你别熬太晚，语气克制 |
| 清晨 | 06:00–09:30 | 道声早，问问吃没吃早饭 |
| 午间 | 11:30–13:00 | 一句午饭/午休 |
| 晚间 | 18:00–20:00 | 问问晚饭、今天累不累 |

设置里还能选关心程度（不打扰 / 温和 / 热情），并且能写「人设补充」，
比如"叫我小林、说话简短点"。

## 记录面板：看得见，才敢删

右上角 ☰ → 「📅 按天查看 · 清理记录」：

- **按天分组**，点一天能展开当天全部对话（我 / 小深 分开标色）
- **日期筛选**（起止日期）+ **关键词搜索**
- **单天删除**，或按日期**批量删除**（"删除 X 之前的全部记录"）
- 顶部有**存储占用条**：`已用 0.42 MB / 5 MB（8%）`
- **导出备份**（JSON），导出的文件里已经去掉 API Key

> 浏览器给 localStorage 的额度是 **5 MB**（约 200 万汉字）。
> 按每天 40 条、每条 60 字估算，纯文本大概两年会顶到上限；到那时写入会失败。
> 所以建议：定期用「删除 X 之前」清掉旧记录（自动滚动清理还没做）。

### 每日摘要

在同一个「记录」面板里，每一天都可以有一段摘要：

- **生成**：点某一天的「生成摘要」，模型把当天对话压成 1–3 句事实
- **自动**：默认开启，每天第一次打开时会把"昨天还没摘要"补上（可在面板里关掉）
- **查看**：摘要直接显示在日期下面，两行折叠，点开当天可看全文
- **编辑**：点「编辑」自己改，你写得比模型好就用你的
- **真的会用上**：最近 5 天的摘要会作为「最近几天的记忆」注入系统提示词，
  所以它记得前几天聊过什么——这才是摘要的意义
- 删掉某天的记录，那天的摘要也会一起消失
- 成本：一天一次调用，约 **0.0005 元**

## 课表：粘贴一次，它就知道了

☰ → **📚 我的课表**。有两个入口：批量粘贴，或者一条条手填。

### 批量导入（最接近「一键」的做法）

把课表按行粘进去，一行一节，格式很宽容：

```
周一 08:00-09:40 数据结构 @教三204 1-16周
周一 10:00-11:40 大学英语 @外语楼301 1-16周
周三 14:00-15:40 计算机组成原理 @教二108 1-16周
周五 19:00-20:40 电影鉴赏 @艺术楼 3-8周
```

能认的写法：

- 星期：`周一` / `星期一` / `周1`
- 时间：`08:00-09:40`（全角数字也行）
- 教室：`@教三204`，或者用逗号分隔 `数据结构，教三204`
- 周次：`1-16周` / `1,3,5周` / `单周` / `双周`，不写就默认 1–16 周

点「解析预览」先看能认几行，再点「导入」。

> **为什么不能真·一键**：教务系统要登录、有验证码、每个学校接口都不一样，
> 纯前端网站没法直接抓。但"从教务系统把课表复制出来粘进去"通常一次就成，
> 这已经是最省事的方式了。

### 填完之后它多了什么本事

1. **对话里带上课表**：今天有几节课、几点、在哪，下一节还有多久，都会写进提示词。
   你问"我今天有课吗""下节课在哪"，它答得出来。
2. **顶部提示条**：12 小时内有课时，输入框上方会出现
   `📚 还有 35 分钟 · 数据结构 · 教三204（08:00）`，20 分钟内变成 ⏰ 并高亮。
3. **单双周自动过滤**：填了「学期第一周的周一」之后，能算出第几周，单周课不会在双周出现。

### 直接跟它说就能改课表

不用开面板，在聊天里说人话就行：

> "周二的大学英语换到外语楼305"
> "周四下午加一节体育，14:00-15:40，操场，1-16周"
> "把电影鉴赏删了"

它会先回一句话，然后在气泡下面显示一条绿色的 **📚 课表已更新** 记录，课表立刻生效。

**原理**（这也是这个项目里最像"agent"的一块）：系统提示词里带了一份操作协议，
要求模型在真要改课表时，把动作写成结构化标签：

```
<op>{"action":"update","name":"大学英语","field":"room","value":"外语楼305"}</op>
```

App 收到后把标签从正文里剥掉、解析成 JSON、校验、改数据、重绘课表。
标签本身不会显示给用户——用户只看到"改好了"和一行变更记录。

> 为什么要用标签而不是让模型直接改数据？因为模型不能碰你的存储，
> 它只能"表达意图"，**真正动手的永远是代码**。这条边界很重要。

### 对话录入：让它问你

课表面板最上面有个 **「💬 开始对话录入」**。点进去会新开一个对话，它一节一节问：

```
它：咱们一节一节来。先从周一开始——周一有课吗？几点、什么课？
你：有，8 点，数据结构，教三204
它：记下了。周二呢？
你：没有课
它：好，那周三呢？
```

每问完一节，它就输出一个 `<op>` 标签，App 立刻存进去，气泡下面显示绿色的变更记录。

规则写死在提示词里：**一次只问一个问题、每次回复不超过两行、信息齐了立刻落库**。
说"好了"它就总结收尾。

> 这套只比普通聊天多了一个东西：**换了一版系统提示词**。界面、存储、op 解析全是复用的——
> 这就是前面那套"标签协议"的好处：加一个场景，只需要换一段话。

### 限制（说实话）

- 提示条**只在网页打开时更新**。浏览器关了，网页就没了，它不会在后台弹通知。
  要真正的"到点自动提醒"，得有后端定时任务 + 推送（见下面"下一步"）。
- 调课、停课、临时换教室，目前要手动改。

## 图片：拍题、拍课表

输入框左边的 **📷** 可以选图/拍照。

- **拍题目**：直接发图，说"这道题怎么解"。它会先逐字读出题目（数字、符号、上下标），确认后再解答；看不清会直接说看不清，不猜。
- **拍课表**：发课表截图，说"录进去"，它会用操作协议批量建课。
- 自动压缩到长边 **1280px / JPEG 0.85**（看清细节和体积的折中，单张约 250 KB）
- 每张图计费**上限 1024 token**（约 0.002 元），跟尺寸无关

### 存储：只留一天

图片体积大，所以单独放在 **IndexedDB**（容量几百 MB），文字仍在 localStorage：

```
localStorage  →  消息文字 + 图片 ID
IndexedDB     →  图片二进制
```

**清理规则**（满足任一即删，删后消息里留「📷 图片已于 X 清理」）：

1. 跨天（本地日期变了）
2. 当天摘要生成之后
3. 当天超过 30 张

另外，如果文字存储接近 4.4 MB，会自动删最老的原文（摘要保留），保证写入永远不会失败。

### 上下文里只带最近 2 张图

多轮对话会把历史整段重发。如果带 5 张图，每轮就是 5×1024 token。所以只让**最近 2 张**图参与上下文，更早的降级成「（此前发送过一张图片）」。

> 注意：**图片会上传给 DeepSeek**。文字仍然只存本地，但别指望图片也"不出门"。

## 数据与费用

- **Key 和聊天记录只存在这台手机的浏览器里**（localStorage），没有任何服务器，也不会上传。
- 代价：清除浏览器数据 / 换手机就没了。用「记录」面板可以导出 JSON 备份。
- 费用：按 token 走 DeepSeek 官方计价，普通聊天一次大约几分钱。

## 想要一个真正的 .apk

1. 先按上面把网页部署到 https 地址
2. 打开 <https://www.pwabuilder.com/>，输入你的网址 → Package for Android → 下载
3. 得到签名的 apk，传到手机安装（要允许「未知来源」）

> 注意：PWABuilder 用的是 Bubblewrap / TWA，本质仍是打开你的网页，
> 所以跨域问题照样存在，仍然需要那个 Worker。

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 401 | Key 不对，或复制时带了空格 |
| 402 | 余额不足，去 platform.deepseek.com 充值 |
| 429 | 请求太频繁或额度受限，等一会儿 |
| 连不上 | 先查网络，再查 CORS（见上） |
| 回复答到一半停了 | 点右下角 ■ 停止；120 秒没响应会自动中断 |
| 时间不对 | 用的是手机系统时间，手机时间不准它就跟着不准 |
| 记录没了 | 清了浏览器数据，或换了浏览器/手机 |
