# 时光 · 会看时间的 DeepSeek

一个装在手机主屏上的聊天 App：接你自己的 DeepSeek Key，它知道现在几点、你们多久没聊，
在深夜、清晨、饭点这种合适的时候自然关心你一句——但绝大多数回复里根本不提时间。

---

## 先说清楚形式：为什么是"网页 App"而不是 APK

这台开发机没有 Android SDK / Gradle，沙箱里也没有外网（下不了 SDK），
所以没法在这里直接编译出 `.apk`。因此做成了 **PWA**：用 https 网址打开后
「添加到主屏幕」，安卓上就是一个全屏、带图标、能离线打开的独立 App，体验和原生几乎没差。

如果你确实要一个能转发的 `.apk` 文件，README 最后有 **PWABuilder** 的路线（需要你先部署网页）。

## 5 分钟上手

### 第 1 步：拿 API Key

1. 打开 <https://platform.deepseek.com/api_keys>，登录后创建 Key（`sk-` 开头），复制。
2. 同一个站点里充几块钱。按量计费，日常聊天一次也就几分钱。

模型名填 `deepseek-flash`（当前默认，快且便宜）或 `deepseek-v4-pro`（更强，更贵）。
设置里是输入框 + 候选，接口改了模型名你直接手输就行。

### 第 2 步：把 App 放到一个 https 网址上

**必须 https**，否则不能「添加到主屏幕」、也没有离线缓存。

- **GitHub Pages（推荐，免费）**
  1. 新建一个仓库，把 `index.html`、`manifest.webmanifest`、`sw.js`、`icons/` 传上去（保持同样结构）
  2. 仓库 Settings → Pages → Source 选 `Deploy from a branch` → `main` / `(root)` → Save
  3. 等 1 分钟，访问 `https://你的用户名.github.io/仓库名/`
- **Cloudflare Pages**：Create → Upload assets → 整个文件夹拖进去
- **只想先看看界面**：电脑上双击 `index.html`。界面能用、能聊天，但没有离线缓存和安装。

### 第 3 步：装到手机

1. 手机 Chrome 打开上面的网址
2. 右上角 ⋮ → **「添加到主屏幕」**（或「安装应用」）
3. 桌面出现「时光」图标，点开是全屏的
4. 点右上角 ⚙ → 粘贴 Key → **测试连接** → 出现 ✓ 就可以聊了

## 如果「测试连接」报连不上

先判断是网络问题还是跨域（CORS）问题：

- 手机浏览器直接打开 <https://api.deepseek.com>，如果也打不开 → 是网络问题
- 能打开、但 App 里报连不上 → 基本就是 CORS

解决 CORS：部署 `proxy/cloudflare-worker.js`（免费，约 3 分钟）：

1. <https://dash.cloudflare.com> → Workers & Pages → Create → Worker
2. 把该文件内容整段贴进去，Deploy
3. 得到地址，例如 `https://shiguang.你的名字.workers.dev`
4. App 设置 → **自定义接口地址** → 填这个地址（不用加 `/chat/completions`）

**更安全的玩法**：在 Worker 的 Settings → Variables 里加一个 Secret `DEEPSEEK_API_KEY`，
手机端就可以完全不填 Key，请求由 Worker 补上，Key 不落在手机里。

## 时间感知的实现（重点）

每次发消息前，代码会做三件事：

1. **把时间写进系统提示词**：`2026年5月1日 23:41，星期五，深夜`，外加"距上次聊天 3 小时前"。
   所以问它"现在几点"它是真的知道。
2. **注入行为规则**：明确告诉它「知道时间，但不要为了显得知道而硬提」「一条回复最多一处」
   「对方在讲正事/情绪低落时，先回应内容」。
3. **用代码控制提醒闸门**，不靠模型自觉：
   - 同一时段每天最多提醒 **一次**
   - 两次提醒之间至少隔 **45 分钟**
   - 深夜跨零点算「同一晚」（23:30 提醒过，凌晨 1 点不会再提）
   - 选「不打扰」时完全不注入提醒

设置的「核对一下 → 查看本轮系统提示词」里，能看到本次真正发出去的提示词，方便你自己调。

**提醒时段**（想改就改 `index.html` 里的 `SLOTS` 数组）：

| 时段 | 时间 | 它会做什么 |
|---|---|---|
| 深夜 | 23:30–05:30 | 劝你别熬太晚，语气克制 |
| 清晨 | 06:00–09:30 | 道声早，问问吃没吃早饭 |
| 午间 | 11:30–13:00 | 一句午饭/午休 |
| 晚间 | 18:00–20:00 | 问问晚饭、今天累不累 |

设置里还能选关心程度（不打扰 / 温和 / 热情），并且能写「人设补充」，
比如"叫我小林、说话简短点"。

## 记录面板：看得见，才敢删

右上角 ☰ → 「📅 按天查看 · 清理记录」：

- **按天分组**，点一天能展开当天全部对话（我 / 小深 分开标色）
- **日期筛选**（起止日期）+ **关键词搜索**
- **单天删除**，或按日期**批量删除**（"删除 X 之前的全部记录"）
- 顶部有**存储占用条**：`已用 0.42 MB / 5 MB（8%）`
- **导出备份**（JSON），导出的文件里已经去掉 API Key

> 浏览器给 localStorage 的额度是 **5 MB**（约 200 万汉字）。
> 按每天 40 条、每条 60 字估算，纯文本大概两年会顶到上限；到那时写入会失败。
> 所以建议：定期用「删除 X 之前」清掉旧记录，或者直接换成"摘要 + 只留最近 60 天"的方案（还没做，需要的话说一声）。

## 数据与费用

- **Key 和聊天记录只存在这台手机的浏览器里**（localStorage），没有任何服务器，也不会上传。
- 代价：清除浏览器数据 / 换手机就没了。用「记录」面板可以导出 JSON 备份。
- 费用：按 token 走 DeepSeek 官方计价，普通聊天一次大约几分钱。

## 想要一个真正的 .apk

1. 先按上面把网页部署到 https 地址
2. 打开 <https://www.pwabuilder.com/>，输入你的网址 → Package for Android → 下载
3. 得到签名的 apk，传到手机安装（要允许「未知来源」）

> 注意：PWABuilder 用的是 Bubblewrap / TWA，本质仍是打开你的网页，
> 所以跨域问题照样存在，仍然需要那个 Worker。

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 401 | Key 不对，或复制时带了空格 |
| 402 | 余额不足，去 platform.deepseek.com 充值 |
| 429 | 请求太频繁或额度受限，等一会儿 |
| 连不上 | 先查网络，再查 CORS（见上） |
| 回复答到一半停了 | 点右下角 ■ 停止；120 秒没响应会自动中断 |
| 时间不对 | 用的是手机系统时间，手机时间不准它就跟着不准 |
| 记录没了 | 清了浏览器数据，或换了浏览器/手机 |
